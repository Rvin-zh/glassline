# Assets

- `open-cluely.png` — Linux / cross-platform icon (512x512)
- `open-cluely.icns` — Mac packaging icon (generated by `scripts/generate-mac-icon.js`)
- `chrome.ico` — legacy Windows icon retained for portable builds
- `com.opencluely.assistant.desktop` — helper `.desktop` entry for GNOME portals / shortcuts

Packaging uses `assets/open-cluely.png` for Linux AppImage/RPM builds and
`assets/open-cluely.icns` for macOS dmg/zip builds.
